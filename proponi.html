Crea il progetto con Claude, poi caricalo

La skill di Beyond insegna a Claude Code le regole dei prototipi Coesa: ti fa le domande giuste, configura il tuo GitHub e prepara lo zip che compila questo modulo.

    Scarica la skill

    Un file da dare a Claude Code, una volta sola.

    Scarica la skill
  2. 2

    Installala e inizia

    Apri Claude Code (app desktop) e scrivi:

    Installa la skill di Beyond: estrai %USERPROFILE%\Downloads\beyond-nuovo-progetto.zip nella cartella %USERPROFILE%\.claude\skills\

    Poi chiudi e riapri Claude Code e scrivi: «Voglio creare un nuovo progetto per Beyond». Claude ti guida fino allo zip.
